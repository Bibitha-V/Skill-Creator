3. Playwright automation example

The following is one focused Playwright Test suite. It assumes an authenticated session has been created beforehand through a permitted sign-in and stored at playwright/.auth/google.json. Keep that file out of source control and use a dedicated test account; storage state contains sensitive session data.

import { expect, Page, test } from '@playwright/test';

test.use({ storageState: 'playwright/.auth/google.json' });

class GoogleSearchPage {
  constructor(private readonly page: Page) {}

  async open(): Promise<void> {
    await this.page.goto('https://www.google.com/');
  }

  async expectSignedIn(): Promise<void> {
    await expect(
      this.page.locator('[aria-label^="Google Account"]')
    ).toBeVisible();
  }

  async search(query: string): Promise<void> {
    const searchBox = this.page.getByRole('combobox', { name: /search/i });
    await searchBox.fill(query);
    await searchBox.press('Enter');
  }

  async openOfficialPlaywrightDocs(): Promise<void> {
    const result = this.page.locator(
      'a[href*="playwright.dev/docs/intro"]'
    ).first();
    await expect(result).toBeVisible();
    await result.click();
  }
}

class PlaywrightDocsPage {
  constructor(private readonly page: Page) {}

  async expectOfficialIntroductionPage(): Promise<void> {
    await expect(this.page).toHaveURL(
      /^https:\/\/playwright\.dev\/docs\/intro(?:[?#].*)?$/
    );
    await expect(this.page).toHaveTitle('Installation | Playwright');
    await expect(
      this.page.getByRole('heading', { name: 'Installation', level: 1 })
    ).toBeVisible();
  }
}

test.describe('Google search to official Playwright documentation', () => {
  test('TC-GGL-PLW-001: signed-in user finds Playwright docs and verifies the title',
    async ({ page }) => {
      const google = new GoogleSearchPage(page);
      const docs = new PlaywrightDocsPage(page);

      await google.open();
      await google.expectSignedIn();
      await google.search('Playwright official documentation');
      await google.openOfficialPlaywrightDocs();
      await docs.expectOfficialIntroductionPage();
    }
  );
});
Automation setup Provision the authenticated state locally using the approved account and sign-in process. Protect it as a secret, exclude it from version control, and periodically refresh it when the session expires. Google can change its UI, regional behavior, and search-result markup; review the locators if the page changes. Do not disable account protections to make this test pass.

The title assertion is the primary acceptance check. The URL and page heading assertions additionally confirm that the opened result is the intended official documentation page.

4. Pass / fail criteria

Pass

The signed-in account indicator is visible, the search is submitted, the official documentation introduction page opens at the expected URL, and its document title equals Installation | Playwright.

Fail / blocked

Fail: The wrong destination opens, the title differs, or the required page cannot be located after a valid search.

Blocked: The authorized session is unavailable/expired, Google requires a human security challenge, or internet access is unavailable. Resolve through the approved sign-in flow; do not bypass security controls.
